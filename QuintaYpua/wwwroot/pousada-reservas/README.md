# Pousada Reservas

Este projeto é uma aplicação web para gerenciar reservas em uma pousada. Ele permite que os usuários façam novas reservas e visualizem detalhes sobre as reservas existentes.

## Estrutura do Projeto

A estrutura do projeto é a seguinte:

```
pousada-reservas
├── wwwroot
│   ├── js
│   │   └── novosClientes.js       # Lógica do lado do cliente para submissão de novas reservas
│   ├── css
│   │   └── style.css              # Estilos para as páginas web
│   ├── reservas.html              # Página que exibe os detalhes das reservas
│   └── index.html                 # Ponto de entrada principal do site
├── README.md                      # Documentação do projeto
```

## Como Usar

1. **Clone o repositório:**
   ```
   git clone https://github.com/seu_usuario/pousada-reservas.git
   ```

2. **Abra o arquivo `index.html` em um navegador:**
   - Este arquivo contém o formulário para novas reservas.

3. **Preencha o formulário e envie:**
   - As informações da reserva serão armazenadas no armazenamento local do navegador.

4. **Visualize as reservas:**
   - Acesse `reservas.html` para ver os detalhes das reservas feitas.
